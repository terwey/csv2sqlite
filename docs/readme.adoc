== Compilation

Requirement is a working Go installation, see <https://go.dev>

.csv2sqlite
[source,bash]
----
make csv2sqlite
# or for mac
make csv2sqlite_mac
----

.sqlite-compare
[source,bash]
----
make sqlite-compare
----
